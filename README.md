# Hairstyle AI

An AI-powered hairstyle recommendation app that uses facial landmark detection and computer vision to analyze your face and suggest the best haircuts for you.

Before running project, run this in terminal: pip install -r requirements.txt

## Features
- Live camera feed with facial landmark detection
- Face shape and proportion analysis
- AI-powered haircut recommendations
- Detailed barber brief you can bring to your appointment

## Requirements
- Python 3.10+
- A webcam
